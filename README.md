## ⚡ Overview

A GTA-inspired, high-performance developer portfolio featuring:
- **Interactive Sunflower Cursor**: Custom cursor with interactive hover scaling, rotation, and click animations.
- **Audio Effects**: Custom GTA sound effects on click events calibrated at an optimal, comfortable volume.
- **Vice City Light / Dark Themes**: Persistent theme switcher with high contrast aesthetics.
- **Interactive Terminal Easter Egg**: Quake-style dropdown terminal (`Ctrl + ~`) for command-line navigation.
- **Mobile-Responsive**: Accessible layout optimized across mobile, tablet, and widescreen displays.

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/akhila-pynam/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
